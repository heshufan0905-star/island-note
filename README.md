# 随手记 · Island Note

一只待在桌面边上的小幽灵。鼠标碰一下，展开就能写。

做它的起因很简单。记一句话，我不想先打开一个大首页，再找新建按钮。平时让它安静收着，需要的时候伸手就能用，写完继续做自己的事。

现在它还能临时放几个文件入口，顺便看一眼 Codex 还剩多少额度。功能先做到这里，尽量把展开、收起和输入这些每天会碰到的小事做好。

## 用起来是什么样

鼠标靠近小幽灵就会展开，移开后稍等一会儿收起。开始打字、打开设置或点了固定按钮，它会保持展开。点击外部或按 Escape 可以结束编辑，中文组词时不会被 Escape 误关掉。

便签只有一张，支持普通文字和勾选事项。输入 `[] ` 或 `- [ ] ` 就能把当前行变成待办，也可以点「添加待办」。勾完留在原处，不会突然跑到别的地方。

拖着文件或文件夹靠近小幽灵，会打开文件区。放进去的是原文件的快捷入口，支持打开、在 Finder 中定位和拖出。重复放同一个文件不会多出一份，移除入口也不会删除原文件。文件被移动后会尽量跟踪，找不到时可以重新定位。

位置可以拖动，主题、字号、不透明度和悬停开关都能在设置里调整。自带暖纸、玻璃、墨色和淡粉四套幽灵主题，也跟随系统的减少动态效果偏好。

## 先跑起来

这是一个 macOS 桌面 App，运行目标为 macOS 14 及以上。目前从源码构建，还没有可直接下载的签名安装包。

准备好 Apple Command Line Tools，然后在终端运行下面几行。

```sh
git clone https://github.com/heshufan0905-star/island-note.git
cd island-note
./scripts/build-macos.sh
open dist/随手记.app
```

构建使用系统的 Swift、AppKit 和 WebKit，不需要安装 npm 包。本项目在 Swift 6.3 上验证过，工具链需要支持 `-default-isolation MainActor`。如果旧版命令行工具报参数不支持，请先更新工具链。

生成的 App 使用本机临时签名，构建的是当前电脑架构。要在另一台 Mac 上用，建议在那台电脑重新构建。

如果一时找不到窗口，菜单栏的双眼图标可以把它找回来，也可以从那里退出。

## Codex 额度按需打开

第一次运行默认关闭。在设置里启用前，先确认本机有可用且已登录的 Codex 客户端或 CLI。

启用后，通过本地 Codex App Server 读取账号额度，大约每分钟更新一次。顶栏常驻显示小圆环和剩余比例，多个额度窗口取最低余量；低于 20% 和 5% 时分别提醒一次。

界面的「Codex Pro」是当前显示名。剩余百分比来自接口，不会按这个名字猜订阅类型，也不会换算成虚构的剩余 token 数。断线时保留上次数据并标明，拿不到数据就显示空值。

这个功能不会创建 Codex 任务或调用生成接口，登录凭证仍由 Codex 管理。随手记本身没有后端，也不要求注册账号。

## 消息提醒还有限制

设置里可以检查微信、QQ、飞书的本机未读标记。需要辅助功能权限，而且原 App 必须暴露可读取的标记，才能开放对应开关。

能读到哪个 App 有未读，就显示哪个 App；拿不到可靠数量就不编数字。点击只会打开原 App，不读取消息正文，也没有回复功能。不同版本的通讯 App 表现可能不同，这部分还需要继续验证。

## 数据放在哪里

桌面版的数据保存在本机。

```text
~/Library/Application Support/IslandNote/
├── note-v1.json          便签和设置
├── files-v2.json         文件引用
├── position-v1.json      窗口位置
└── codex-quota-v2.json   额度缓存
```

文件区不复制或上传原文件。便签暂时没有云同步，换电脑前请自己备份这个目录；原文件也需要单独保留。

## 想改一改

界面是 HTML、CSS 和原生 JavaScript，桌面部分用 Swift 写。AppKit 负责悬浮窗口、拖放、文件书签和系统权限，WebKit 负责便签与设置。窗口大小和内容显隐由同一套弹簧状态驱动，动画中途可以反向，不必等它播完。

```text
native/     桌面窗口、文件、额度和未读标记
app.js      便签编辑与设置
v2.js       文件区和集成数据的界面
styles.css  主题与排版
scripts/    构建和检查脚本
tests/      原生功能检查
```

检查可以直接运行。

```sh
./scripts/test-native.sh
node --check app.js
node --check v2.js
```

原生检查覆盖文件引用持久化、重复文件、移动和失效处理，也检查额度解析、提醒去重、窗口边界和动画反向。浏览器里直接打开 `index.html` 可以看基本界面，文件书签、真实额度和系统材质需要在桌面版里使用。
